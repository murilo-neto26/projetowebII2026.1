Funcionalidades (checklist)  
*🧠 1. Biblioteca inteligente de desenhos*

_Uma base de dados interativa._

>> Funcionalidades:

- Busca por década (anos 60, 70, 80, etc.)

- Filtro por gênero (comédia, aventura, mistério…)

- Sessões temáticas (ex: “desenhos esquecidos”, “clássicos dos sábados”)

*🎨 2. Criador de listas personalizadas*

_Uma funcionalidade onde o usuário pode criar listas com seus desenhos favoritos, funcionando como um “portfólio pessoal de nostalgia”._

>> Funcionalidades:

- Criar listas como: “Top 10 da infância” ou “Melhores vilões”

*🧩 3. Quiz e desafios interativos*

_Área do site voltada para jogos e testes sobre desenhos antigos._

>> Funcionalidades:

- Quiz de reconhecimento de personagens

- Perguntas sobre quantidade de episódios ou nome de personagens

*🧾 4. Arquivo histórico e curiosidades*

_Seção informativa com conteúdos mais aprofundados sobre os desenhos e sua história._

>> Funcionalidades:

- Curiosidades sobre episódios e personagens

- Bastidores da produção

- Informações sobre estúdios

- Comparação entre versões antigas e remakes
